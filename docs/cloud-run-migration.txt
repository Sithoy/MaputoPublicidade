Container preparation
---------------------
- Build backend/Dockerfile.cloudrun with backend/ as context, never the repo root.
- Supply APP_REVISION as the exact full tested Git commit; release builds must use clean source.
- Cloud Build uses backend/cloudbuild.cloudrun.yaml with required _REVISION and
  _IMAGE substitutions; it deliberately does not deploy or switch traffic.
- Gunicorn binds 0.0.0.0:$PORT; the app runs as UID 10001.
- Static files are collected at build time without production credentials.
- Runtime .env loading is disabled. The startup guard reports only variable names.
- Gunicorn request access logging is not enabled: private approval URLs must not
  be copied into application logs. Configure Cloud Logging handling for sensitive
  request URLs before cutover; retain sanitized security/operational telemetry.
- Startup does NOT migrate, seed data, create accounts or reset passwords.
- Health must return 200, db=true and X-MP-Release matching the release SHA.
- Django keeps HTTPS redirects enabled. A local HTTP smoke check must send
  X-Forwarded-Proto: https and a Host accepted by ALLOWED_HOSTS.
